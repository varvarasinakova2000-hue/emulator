# Эмулятор UNIX-оболочки (вариант 25)

## Общее описание

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом
на Python + Tkinter. Окно состоит из области вывода, поля ввода команды
и кнопки «Enter». Заголовок окна строится по реальным данным ОС:
`Эмулятор - [username@hostname]`.

Текущий этап — **этап 1 (REPL)**: минимальный прототип, команды пока
являются заглушками.

## Структура

```
src/main.py         — исходный код эмулятора
tests/test_main.py  — тесты
run.bat, run.sh     — скрипты запуска
```

## Функции и команды

| Команда | Описание |
|---------|----------|
| `ls [аргументы]` | заглушка: выводит имя команды и аргументы |
| `cd [аргументы]` | заглушка: выводит имя команды и аргументы |
| `exit` | закрывает эмулятор |

Ввод разделяется на команду и аргументы по пробелам.

Обработка ошибок:

- неизвестная команда — `shell-emulator: command not found: <имя>`;
- `exit` с аргументами — `shell-emulator: exit: too many arguments`.

Функции в `src/main.py`:

- `get_user_and_host()` — имя пользователя и компьютера из ОС;
- `parse_command(line)` — разбор строки на команду и аргументы;
- `execute(command, args)` — выполнение команды, возвращает текст вывода;
- `TerminalEmulator` — окно эмулятора.

## Настройки

На этапе 1 настроек нет. Параметры командной строки (путь к VFS и
к стартовому скрипту) появятся на этапе 2.

## Сборка, запуск и тесты

Требуется Python 3 (Tkinter входит в стандартную поставку).
Сборка не требуется, сторонние зависимости не используются.

Запуск эмулятора:

```
run.bat        # Windows
./run.sh       # Linux / macOS
```

Запуск тестов:

```
python -m unittest discover -s tests
```

## Пример использования

```
User@DESKTOP:~$ ls
Вызвана заглушка команды: ls
Переданные аргументы: [нет аргументов]

User@DESKTOP:~$ cd /home user
Вызвана заглушка команды: cd
Переданные аргументы: /home user

User@DESKTOP:~$ foo
shell-emulator: command not found: foo

User@DESKTOP:~$ exit 1
shell-emulator: exit: too many arguments

User@DESKTOP:~$ exit
```
